## 2. 자동 검증 (`src/verify.py`, 62개 항목 전부 통과)

- 교육자료의 도구 32개가 스킬팩 `reference/tools-index.md`와 정확히 일치
- 본문에 나오는 도구·파라미터 이름(snake_case)이 모두 실제 이름
- T01~T18이 가리키는 워크플로 파일 18개가 모두 존재하고, 순서가 `workflows-index.md`와 같음
- 실습 프롬프트 14개와 템플릿 19개(T00 포함)가 슬라이드와 워크북에 같은 문구로 들어 있음
- 33장 모두 발표자 노트 있음
- 이모지, 줄표(—), 느낌표, 상투적 과장 표현 없음

두 파일 모두 Office 스키마 검사(validate.py)를 통과했다.

## 4. 독립 검토 결과와 조치

제작자와 별도로 검토자가 두 파일 전문을 공식 스킬팩과 대조했다. 지적 사항과 조치는 다음과 같다.

| 지적 | 조치 |
|------|------|
| "MCP는 모듈을 만들지 않는다"는 틀림 (create_api_module이 있음) | "화면을 스캔해 UI 모듈을 만들지 못한다"로 전부 수정 |
| 프롬프트 2-1의 작업 상태 변경이 Commander를 멈출 수 있음 | set_attribute로 바꾸라는 문장 추가, T00 규칙 5와 부록 B 확대 |
| Lab 4 프롬프트가 저장 없이 실행 → 바꾼 값이 실행에 안 들어갈 수 있음 | 4-1, 4-2, 4-4에 "저장한 다음" 추가, 준비 항목에 이유 명시 |
| Lab 3에서 비밀번호를 프롬프트에 입력 → 클라우드 모델로 전송 | TCP 참조 `{CP[DWS_Password]}` 방식으로 변경, 강사 준비 항목 추가 |
| 5-2가 선택 체크인처럼 읽힘 | check_in_all이 체크아웃한 객체 전부에 적용된다고 명시 |
| 5-1은 대화 기록에 의존 | "한 대화창에서 진행" 안내를 워크북 사용법과 Lab 5에 추가 |
| 휴식 전 125분 연속 | 휴식을 Lab 3 뒤로 이동 |
| "현재 제공되는 템플릿 18종"이 Tricentis 제공으로 오해될 수 있음 | "공식 워크플로 18종(Tricentis 제공) + 대응 프롬프트 템플릿(이 과정에서 작성)"으로 구분 |
| "현업에서 많이 쓰는"은 근거 없음, API 사례에 템플릿 없음 | "업무에 써 볼 만한"으로 수정, API 프롬프트 예시 추가 |
| 멀티 유저 순서에서 update_all 위치 오류, Checkout 누락 | "시작: update_all → Checkout / 끝: save_workspace → check_in_all"로 수정 |
| "Unknown task" 대처가 부정확 | "작업 목록을 다시 보고 정확한 이름으로" 우선, 체크아웃 대상 구분 |
| 스킬팩을 '권장'으로 표기 (README는 둘 다 필요하다고 함) | 설치 전제로 수정, VS Code·Claude Desktop 한계 안내 추가 |
| 템플릿 번호 때문에 AI가 워크플로를 따른다는 오해 | "AI는 요청 내용에 맞는 워크플로를 고른다"로 수정 |
| 강사 준비 자료와 실패 시 대안 없음 | 설계안에 강사 사전 준비 체크리스트, Lab 3에 완성본 복사 대안 추가 |
| 슬라이드 9 "모듈 5개" 불일치, 슬라이드 21 도구 목록 누락 | "모듈을 6번 끌어다 놓아", save_workspace 추가 |
| 기계적으로 읽히는 문장 (USB-C 비유, "습관 일곱 가지", 표어식 문장 등) | 지적된 문장 모두 고쳐 씀 |

반영하지 않은 것: 워크북 표 안의 짧은 서술을 모두 명사형으로 바꾸자는 의견은, 표 안은 "~한다"체, 본문은 "~합니다"체로 나누는 것이 사내 교육 문서에서 흔한 방식이라 유지했다. 슬라이드 20의 Commander 화면 예시는 공간 때문에 URL을 줄여 표시했다(계획 표에는 전체 URL).

## 5. 화면 점검

LibreOffice로 모든 슬라이드와 페이지를 이미지로 만들어 한 장씩 확인했다. 찾아서 고친 문제: 제목 가운데 정렬, 표 셀 여백 단위 오류로 표 3개가 깨짐, 화살표 방향 반대, 긴 제목과 Lab 표시 겹침, 템플릿 표와 본문이 페이지에서 갈라짐, 거의 빈 페이지, 요소 겹침 2건.

미리보기는 맑은 고딕 대신 Noto Sans KR로 렌더링했다. 실제 PowerPoint·Word에서는 줄바꿈 위치가 조금 다를 수 있다.

## 6. 교육 전에 강사가 확인할 것

- 표준 모듈 CloseBrowser의 속성 이름(Title)과 폴더 위치: 문서에서 속성 목록까지는 확인하지 못했다.
- Demo Web Shop의 로그인 실패 문구('Login was unsuccessful'): 실제 화면에서 한 번 확인한다.
- 실제 도구 목록: Commander 패치에 따라 다를 수 있으므로 Lab 0의 도구 목록 요청으로 확인한다.
- ExecutionList 실행(T08): 2026.1 문서와 스킬팩 1.2.0 변경 내역의 설명이 다르다. 사용하는 패치에서 시험해 본다.
- Claude Desktop의 스킬 설치 방법: 스킬팩 안내에 없어 사내 관리자 확인이 필요하다.
- 제작 환경에서 docs.tricentis.com 접속이 막혀 있어, Tricentis 문서 내용은 검색 결과로 확인했다. 공식 스킬팩(GitHub)은 직접 받아 대조했다.
